Política de privacidad

Cómo se tratan los datos personales enviados por los usuarios.

Datos recopilados

Credisnet puede recibir datos identificatorios, de contacto, laborales, bancarios y documentación de respaldo que el usuario envía voluntariamente para evaluar y gestionar una solicitud.

Finalidad

Los datos se utilizan para responder consultas, verificar requisitos, preparar el legajo, presentarlo ante una entidad otorgante cuando corresponda y cumplir obligaciones legales.

Compartición

La información puede compartirse con entidades otorgantes y proveedores necesarios para la operatoria, con el alcance requerido y conforme al consentimiento del titular. No se comercializan bases de datos ajenas al servicio solicitado.

Seguridad

Se aplican medidas razonables de protección, aunque ningún sistema de transmisión o almacenamiento es completamente infalible.

Derechos

Conforme a la Ley 25.326, el titular puede solicitar acceso, rectificación, actualización o supresión de sus datos escribiendo a info@credisnet.com.

Cookies y analítica

El sitio puede usar cookies técnicas y analíticas, incluido Google Analytics, para medir el uso y mejorar la experiencia. El usuario puede gestionarlas desde su navegador.
